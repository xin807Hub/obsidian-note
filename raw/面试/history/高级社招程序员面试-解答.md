# 高级社招程序员面试参考解答

说明：
- 本文对应 `高级社招程序员面试.md`。
- 回答时不要只给概念，最好补一层项目场景、常见故障和取舍。

## 一、系统设计与性能

### 1. 资源隔离怎么做？

参考答法：
- 资源隔离通常分为计算、内存、网络、存储、线程池和租户维度几个层面。
- 单机层面可以依赖容器或进程级隔离，比如 CPU 配额、内存限制、文件句柄、磁盘配额。
- 应用层还要做线程池隔离、连接池隔离、队列隔离，避免一个慢业务拖垮全局。
- 如果是多租户系统，通常还要做租户级限流、配额和数据隔离，防止热点租户挤占公共资源。
- 面试里最好补一句：资源隔离不是目的，核心是把故障域缩小，让单点问题不会扩散成整体雪崩。

### 2. 性能优化怎么做？

参考答法：
- 先量化再优化，不要上来就改代码。先看接口 RT、吞吐、CPU、内存、GC、SQL、缓存命中率。
- 再按链路拆分瓶颈：是计算慢、IO 慢、锁竞争、数据库慢，还是网络抖动。
- 常见手段包括：缓存、异步化、批处理、索引优化、对象复用、减少序列化、连接池调优、热点隔离。
- 优化完成后要做压测和回归，验证收益与副作用，比如命中率提升了多少、时延下降了多少、峰值下是否稳定。
- 高级岗位回答里最好体现方法论：监控定位、假设验证、最小改动、灰度发布、持续观测。

## 二、网络与传输

### 3. 讲讲 Socket 编程。

参考答法：
- Socket 编程本质上是基于传输层协议建立进程间通信，最常见的是 TCP 和 UDP。
- TCP 场景下，服务端一般是 bind、listen、accept，客户端 connect，建立连接后再收发数据。
- 真正工程里重点不是 API，而是连接生命周期、心跳保活、超时控制、半包粘包处理、背压和异常重连。
- 高并发服务通常不会一连接一线程，而是基于 IO 多路复用或 Netty 这类事件驱动框架处理。
- 如果你做过项目，可以补充实际问题，比如连接数过多、发送缓冲区堆积、空闲连接清理、协议解析失败等。

### 4. 粘包、拆包怎么处理？

参考答法：
- TCP 是字节流，没有消息边界，所以应用层必须自己定义协议边界。
- 常见做法有三种：固定长度、分隔符、长度字段加消息体，其中最常见的是长度字段协议。
- 发送端可能把多条消息合并发送，接收端也可能一次只收到半条，因此必须有累积缓冲区。
- 解码时先判断缓冲区里是否拿到了完整包头，再根据长度字段判断消息体是否完整，不完整就继续读。
- 实战里还要做非法包长度校验，避免因为脏数据或恶意流量导致内存被打爆。

### 5. 怎么实现断点续传？

参考答法：
- 核心思想是把大文件拆成多个分片，每个分片独立上传，并在服务端记录上传状态。
- 客户端首次上传前先拿上传任务 ID，之后按分片序号上传；失败重试时只补未完成分片。
- 服务端一般要记录文件标识、分片总数、已完成分片、校验值和最终合并状态。
- 全部分片上传完成后触发合并，再做完整性校验，比如文件大小、MD5 或分片校验和。
- 生产里还要考虑并发重复上传、过期分片清理、秒传判重、对象存储残余碎片清理。

## 三、数据库

### 6. MySQL 开窗函数怎么用？

参考答法：
- 开窗函数适合“保留明细行，同时做组内排名、累计、对比上一行下一行”这类场景。
- 常见函数有 `row_number()`、`rank()`、`dense_rank()`、`sum() over (...)`、`lag()`、`lead()`。
- 典型用法比如：找每个用户最新一条记录、查连续打卡、做分组 TopN、算累计金额。
- 面试里要说明 `partition by` 是分组范围，`order by` 是窗口内排序规则。
- 还要补一句：开窗函数可读性强，但大数据量下仍要关注排序和临时表开销，必要时配合索引和执行计划分析。

## 四、Java 语言基础

### 7. Java 方法传参是值传递还是引用传递？

参考答法：
- Java 永远只有值传递。
- 基本类型传的是值本身；对象传的是“引用变量里保存的地址值”的副本。
- 所以很多人误以为对象是引用传递，本质上仍然是值传递，只是这个值恰好是地址。

### 8. 如果把一个对象传进方法，在方法里修改对象属性，外面的对象会不会变？

参考答法：
- 会变。
- 因为方法参数和外部变量虽然是两个不同引用变量，但它们指向同一个对象实例。
- 在方法里改的是对象内部状态，不是把外部引用重新绑定，所以调用方能看到修改结果。

### 9. 如果在方法里重新 new 一个对象赋给参数，外面的对象会不会变？

参考答法：
- 不会变。
- 因为你只是让方法内部那个参数引用指向了新对象，外部引用仍然指向原来的对象。
- 这正好说明 Java 传参不是引用传递，否则外部引用会一起被改掉。
