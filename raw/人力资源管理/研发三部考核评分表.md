# **二、考核目的**

对员工入职两个月以来的技术能力、业务理解、执行力与成长性进行阶段性评估，用于确定是否进入下一阶段培养计划或采取进一步管理措施。

------

# **三、考核方式**

- 工作汇报 PPT（结构化汇报能力）
- 代码 Review（工程能力）
- 现场问答（理解深度、主动性、思考能力）
- 日常工作表现回顾（推进力、自主性）

------

# **四、能力维度量化评分**

| 能力项         | 预期表现                       | 实际表现               | 评分（1-5） | 备注 |
| -------------- | ------------------------------ | ---------------------- | ----------- | ---- |
| 模块理解与拆解 | 能清晰描述模块职责、流程、边界 | 表达混乱，理解不完整   |             |      |

| 沟通与表达     | 汇报清晰、有思路               | 表述混乱、逻辑跳跃     |             |      |
| 综合成长性     | 学习曲线明显                   | 提升有限、变化不大     |             |      |

# **五、评分标准说明**

**5 分：远超预期，可独立完成复杂任务**
 **4 分：达到预期，表现稳定**
 **3 分：基本达标，但不稳，需要持续跟进**
 **2 分：明显低于预期，需要重点辅导**
 **1 分：严重不达标，无法胜任岗位要求**

3. **业务理解不够**
   - 无法说明模块上下游关系
   - 难以从业务角度解释功能价值
4. **总体成长性偏弱**

   - 工程意识不足，缺乏反思与复盘
