## 社招研发工程师培养计划大纲（最终版）

以下为社招研发工程师入职后的能力对齐与培养要求。本计划目标是：**尽快融入现有技术体系，具备独立承担模块级开发与交付能力**。

## 一、后端核心能力（必知必会）

### 1. Golang 后端能力（重点）

必须具备以下能力：

- 熟练掌握 Go 语言基础语法与常用标准库
- 熟悉主流 Web 框架（Gin）
- 能基于现有项目（如 gin-vue-admin）**独立完成模块级 API 设计与实现**
- 熟练使用 GORM，理解：
  - 模型设计
  - 常见 CRUD
  - 事务、索引、性能注意点

参考资料：

- Go 语言资料合集：https://github.com/yongxinz/gopher
- gin-vue-admin：https://www.gin-vue-admin.com/
- GORM 官方文档：https://gorm.io/

------

### 2. HTTP 接口规范与调试能力（必会）

- 熟练编写 Swagger 接口文档，并能持续维护更新
- 熟练使用 HTTP 接口测试工具：
  - 推荐：IDEA HTTP Client
  - 可选：Postman
- 理解 HTTP 基础：
  - 请求方法、状态码
  - Header / Body
  - RESTful 接口设计规范

### 3. 线上调试与问题定位能力（必会）
