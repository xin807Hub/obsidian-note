# 居家断舍离完全指南

> 目标：通过系统性整理，减少物品数量，提升生活品质，建立可持续的收纳体系。

---

## 一、前期准备

### 1.1 心态准备
- **接受不完美**：断舍离是过程，不是一次性任务
- **设定边界**：不碰他人物品，先从自己负责的区域开始
- **允许反复**：第一次处理不掉的物品，可以第二轮再决定

### 1.2 物资准备
- 垃圾袋（3种规格）：丢弃物/捐赠物/待处理
- 便签纸 + 记号笔：分类标记
- 计时器：设定单轮整理时限，避免疲劳
- 纸箱/收纳箱：临时存放区域

### 1.3 时间安排
- 建议单次整理时长：1-2小时
- 选择精神状态好的时段
- 避开疲惫或情绪低落时进行

## 二、断舍离五步法

### 第一步：集中（Gather）
**操作**：把同一类别的物品全部取出，放在眼前

| 类别 | 建议整理区域 |
|------|-------------|
| 衣物 | 衣柜 + 床底储物 + 晾晒区 + 行李箱 |
| 书籍 | 书架 + 床头 + 办公桌 + 储藏室 |
| 文件 | 抽屉 + 柜子 + 电子设备 |
| 杂物 | 玄关 + 桌面 + 阳台 + 储物间 |
| 厨具 | 橱柜 + 台面 + 冰箱 + 餐边柜 |

**关键原则**：不遗漏、不预筛选，全部拿出来

---

### 第二步：分类（Sort）
**按以下维度建立临时分类区**：

```
┌─────────────┬─────────────┬─────────────┐
│   保留区    │   待定区    │   处理区    │
├─────────────┼─────────────┼─────────────┤
│ 经常使用    │ 难以决定    │ 丢弃/捐赠   │
│ 季节性使用  │ 情感纠结    │ 转卖/送人   │
│ 有明确用途  │ 可能有用    │ 损坏/过期   │
└─────────────┴─────────────┴─────────────┘
```

**快速决策法**：
- 近1年用过？→ 保留
- 坏了/过期？→ 丢弃
-  duplicates 过多？→ 精简
- 看到时心情沉重？→ 考虑处理

---

### 第三步：丢弃（Discard）

#### 必扔清单（无需犹豫）
- [ ] 过期食品、药品、化妆品
- [ ] 破损/缺件/无配套的物品
- [ ] 多年未穿的衣服
- [ ] 不再使用的充电器/数据线
- [ ] 重复的宣传册/说明书（可拍照留存）
- [ ] 枯萎的植物
- [ ] 用完的瓶瓶罐罐

#### 可捐赠/转卖
- [ ] 尺码不合适的衣物（洗净）
- [ ] 读完不再需要的书籍
- [ ] 孩子不再玩的玩具
- [ ] 闲置小家电（功能完好）

#### 捐赠渠道参考
- 公益组织：飞蚂蚁、白鲸鱼、旧衣回收箱
- 二手平台：闲鱼、转转、多抓鱼（书籍）
- 社区群：邻里赠送

---

### 第四步：收纳（Organize）

#### 4.1 收纳原则
1. **定位原则**：每件物品有固定位置
2. **可视原则**：尽量能直接看到/拿到
3. **动线原则**：常用物品放在顺手处
4. **垂直原则**：利用竖向空间

#### 4.2 常用收纳工具
| 场景 | 推荐工具 |
|------|---------|
| 衣柜 | 抽屉分隔盒、衣架统一、真空压缩袋 |
| 厨房 | 透明储物罐、分层架、挂钩 |
| 桌面 | 文件架、笔筒、理线盒 |
| 卫生间 | 镜柜、壁挂架、分格收纳盒 |

#### 4.3 标签系统
- 贴上物品名称 + 有效期（如适用）
- 统一字体/颜色，便于识别

---

### 第五步：维持（Maintain）

#### 5.1 日常习惯
- **一进一出**：买新物品时，处理一件旧的
- **30秒归位**：用完物品，30秒内放回原位
- **睡前复位**：每天睡前整理台面/桌面

#### 5.2 定期复盘
| 周期 | 内容 |
|------|------|
| 每周 | 快速检视常用区域 |
| 每月 | 检查冰箱/药品有效期 |
| 每季 | 换季衣物整理 |
| 每年 | 全屋断舍离大整理 |

## 三、分区域执行清单

### 3.1 卧室
- [ ] 衣柜：按季节分类，捐赠/丢弃不穿衣物
- [ ] 床底：清空，仅保留季节性物品
- [ ] 床头柜：只放睡前必需品
- [ ] 梳妆台：处理过期化妆品，精简护肤品

### 3.2 客厅
- [ ] 茶几：保持表面整洁，杂物入盒
- [ ] 电视柜：整理线缆，丢弃无用遥控器
- [ ] 书架：未读/不会读的书处理掉
- [ ] 玄关：鞋柜精简，只留当季鞋

### 3.3 厨房
- [ ] 冰箱：清理过期食物，设定食材消耗顺序
- [ ] 橱柜：检查干货保质期，统一容器
- [ ] 台面：只留高频使用物品
- [ ] 抽屉：分类餐具，丢弃破损件

### 3.4 卫生间
- [ ] 镜柜：丢弃过期洗护用品
- [ ] 洗手台：减少台面物品数量
- [ ] 储物柜：毛巾按需保留，破旧改抹布

## 四、常见问题处理

### Q1：舍不得扔怎么办？
- 设置"冷静箱"：放入待定物品，3个月后未取用则处理
- 拍照留念：保留记忆，释放实体空间
- 设定比例：如"这次必须处理掉30%"

### Q2：家人不配合怎么办？
- 从自己区域开始，用行动影响
- 不擅自丢弃他人物品
- 创造整洁环境的正向反馈

### Q3：反弹了怎么办？
- 正常现象，断舍离是循环过程
- 分析原因：是收纳不合理？还是购买冲动？
- 针对性调整，而非放弃

### Q4：买多了收纳盒反而更乱？
- 先断舍离，再考虑收纳工具
- 量好尺寸再购买
- 优先使用现有容器

## 五、进阶：从断舍离到精简生活

### 5.1 购买前的灵魂拷问
1. 家里是否有类似功能的物品？
2. 我会使用它超过一年吗？
3. 如果没有它，我的生活会受影响吗？
4. 我真的需要它，还是只是想要拥有？

### 5.2 精简生活原则
- **少买精买**：选择质量好、耐用、真正喜欢的
- **体验优先**：把钱花在体验而非物品上
- **数字化**：文档、照片、音乐尽量电子化
- **品质 > 数量**：拥有更少，但每件都称心
