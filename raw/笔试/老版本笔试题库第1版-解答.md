## 二、Java 语言基础知识

### 1. `==` 和 `equals` 区别；为什么重写 `equals` 必须重写 `hashCode`

给分点：

- `==`：基本类型比值，引用类型比地址
- `equals`：默认也比地址，但常被重写为“按内容比较”
- 若 `equals` 相等，则 `hashCode` 必须相同
- 否则在 `HashMap`、`HashSet` 中会出现查找/去重异常

### 2. `swap` 代码输出

### 二、问答题

#### 1. `new` 与 `make`

给分点：

- `new(T)` 返回 `*T`
- `make` 只用于 `slice`、`map`、`channel`
- `make` 返回初始化后的类型本身，不是指针

#### 2. channel 设置缓冲和不设置缓冲的区别

给分点：

- 无缓冲：发送/接收必须同步配对
- 有缓冲：缓冲区未满可先发，非空可先收
- 无缓冲偏同步，有缓冲偏解耦

#### 3. 值接收器与指针接收器区别

给分点：

- 值接收器操作副本
- 指针接收器可修改原对象
- 大对象用指针接收器可减少拷贝
- 方法集/接口实现会受影响

#### 4. Go 是否会发生内存泄露，如何定位

给分点：

- 会发生
- 常见场景：goroutine 泄露、大对象被小切片长期持有、`Ticker/Timer` 未停止、缓存或全局 `map` 无限增长
- 定位：`pprof`、`go tool pprof`、看 goroutine/堆内存持续增长

#### 5. Go 垃圾回收机制

给分点：

- 并发标记清除
- 三色标记
- 有短暂 STW
- 写屏障用于保证并发标记正确性

#### 6. Go GMP 模型

给分点：

- G：goroutine
- M：内核线程
- P：调度上下文
- M 绑定 P 才能执行 Go 代码
- `GOMAXPROCS` 影响 P 数量

#### 2. 二分查找

参考答案：

```go
func binarySearch(nums []int, target int) int {
	left, right := 0, len(nums)-1
	for left <= right {
		mid := left + (right-left)/2
		if nums[mid] == target {
			return mid
		}
		if nums[mid] < target {
			left = mid + 1
		} else {
			right = mid - 1
		}
	}
	return -1
}
```
